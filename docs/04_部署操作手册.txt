本地部署与日常操作手册（无代码基础也能用）
════════════════════════════════════════════════════════════

一、一键启动（日常就用这个）
──────────────────────────────────────────────
  双击  D:\伟澳新能源\AIO获客系统\start.bat
  → 浏览器会自动打开 http://localhost:8501
  → 用完直接关浏览器 + 关黑色窗口即可

  首次启动如果报错「streamlit 未安装」，运行一次：
    双击  D:\伟澳新能源\AIO获客系统\安装依赖.bat
  （依赖已预装好，一般不用这一步）

二、每天怎么用（5 分钟上手）
──────────────────────────────────────────────
  【角色A · 内容运营】每天做 3 件事：
    1. 左侧点「1. AIO内容生成」→ 选关键词和场景 → 点「生成」
       → 点「保存到内容库」
    2. 左侧点「2. 内容分发」→ 选刚才的内容 → 选渠道 → 点「记录发布」
    3. 左侧点「5. 项目管理与绩效」→ 「每日任务打卡」→ 填完成数 → 打卡

  【角色B · 数据运营】每天做 3 件事：
    1. 左侧点「3. 排名监测」→ 按提示词去 ChatGPT/Bing 查
       → 回系统填「位次 + 推荐话术」→ 点「记录」
    2. 左侧点「4. 线索效果」→ 有询盘就「录入线索」
    3. 左侧点「5. 项目管理与绩效」→ 打卡

  【老板】月底：
    左侧点「5. 项目管理与绩效」→「绩效核算」→ 选人+月份 → 点「开始核算」
    → 看每人该发多少钱

三、5 个模块一句话说明
──────────────────────────────────────────────
  模块1 生成内容  = 让 AI 有东西可引用（每天4条）
  模块2 分发      = 把内容发到官网/目录站（每天4条）
  模块3 排名监测  = 看 AI 有没有推荐我们（每天10个词）
  模块4 线索      = 记录询盘、算ROI（有就录）
  模块5 绩效      = 打卡 + 算工资（每天打卡，月底核算）

四、数据存在哪 / 怎么备份
──────────────────────────────────────────────
  数据库文件：D:\伟澳新能源\AIO获客系统\data\aio_lighting.db
  （就这一个文件，所有关键词/内容/排名/线索/绩效都在里面）

  备份方法：把这个 .db 文件复制一份到别处即可。
  建议每周五备份一次，命名如 aio_lighting_20260911.db

五、常见问题
──────────────────────────────────────────────
  Q1：双击 start.bat 闪退 / 打不开？
     → 先双击「安装依赖.bat」，装完再启动。

  Q2：浏览器打开了但页面空白？
     → 等 3-5 秒，streamlit 首次启动要初始化数据库。
     → 还不行就刷新页面。

  Q3：ChatGPT 查不到（被封锁）？
     → 改用 Bing AI 或 Google SGE，或用手机热点联网再查。
     → 这是 IP 被 OpenAI 封，不是系统问题。

  Q4：想改公司名/产品参数/认证？
     → 打开 config.py 文件（记事本），改对应文字后重启系统。

  Q5：关键词想加新的？
     → 模块1 的「词库管理」里手动加，或点「自动拓展长尾词」。

六、修改配置（进阶，可选）
──────────────────────────────────────────────
  config.py 里可以改：
    · 公司名/邮箱/WhatsApp（COMPANY 段）
    · 认证列表（CERTIFICATIONS）
    · 产品默认参数（ai_engine.py 的 DEFAULT_PRODUCT）
    · 绩效基数/权重（config.py 的 PERF_RULES）
  改完保存，重启系统生效。
