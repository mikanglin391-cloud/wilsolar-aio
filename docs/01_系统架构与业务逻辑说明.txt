一、这套系统是干什么的
──────────────────────────────────────────────
一句话：让海外 B 端客户在 ChatGPT、Bing AI、Google SGE 里搜
「太阳能路灯 / LED 路灯采购」时，优先看到并推荐伟澳 Wilsolar。

原理（AIO = AI Search Optimization）：
  生成式 AI 搜索（ChatGPT 等）推荐某家供应商，靠的是「它在网上
  有没有被足够多、足够权威、足够新鲜的网页提到」。所以我们要做的
  不是投广告，而是：
    ① 生产大量结构化、场景化、带认证信号的产品内容
    ② 把这些内容铺到官网、Google商家、目录站、LinkedIn
    ③ 让 AI 爬虫抓取收录，从而在回答采购问题时引用我们
    ④ 每天盯着排名变化，哪里掉补哪里

二、技术架构
──────────────────────────────────────────────
  界面层   Streamlit（网页界面，浏览器打开就能用，无需写代码）
  业务层   5 个功能模块（内容生成 / 分发 / 排名 / 线索 / 绩效）
  引擎层   ai_engine.py（本地规则引擎 + 行业词库，离线可用）
  数据层   SQLite（单文件数据库，无需装数据库软件）

  目录结构：
    D:\伟澳新能源\AIO获客系统\
      ├─ app.py              主入口（左侧菜单切 5 个模块）
      ├─ config.py           公司信息 / 词库 / 场景 / 绩效规则（改配置改这里）
      ├─ db.py               数据库建表 + 初始数据
      ├─ ai_engine.py        内容生成引擎（JSON-LD/场景/FAQ/长尾词）
      ├─ modules\            5 个模块代码
      ├─ data\               SQLite 数据库文件（自动生成）
      ├─ export\             导出的 HTML/Markdown 文件（自动生成）
      └─ docs\               4 份文档（架构/甘特图/绩效/手册）

三、5 个模块的业务逻辑
──────────────────────────────────────────────
【模块1 · AIO 智能内容生成】—— 核心排名引擎
  输入：关键词 + 场景 + 产品参数
  输出：标题 + Markdown + HTML + JSON-LD 四件套
  内置 5 条 AI 排名优化规则：
    ① JSON-LD Product Schema：品牌/型号/功率/材质/认证(CE/RoHS/
       ISO/ETL/UL/VDE)/价格/MOQ/场景/质保/案例 全字段结构化
    ② 场景化描述：停车场/厂区/乡村道路/市政/住宅/公路 6 大场景，
       每条内容点出「采购痛点 + 买家画像」
    ③ FAQ + 选型指南 + 安装教程：覆盖 how/why/what 类搜索意图
    ④ 长尾词自动拓展：格式「场景+参数+品类」，
       如 "100W solar street light for industrial park"
    ⑤ 权威信任信号植入：工厂资质/认证/质保/工程案例/MOQ 低门槛

【模块2 · 多渠道内容分发】—— 让 AI 有东西可引用
  管理渠道：官网 / Google 商家档案 / 行业目录站 / LinkedIn
  记录每条内容的发布时间、关键词、平台、URL
  自动算「内容新鲜度」（AI 偏爱新鲜内容，≤30天为新鲜）
  自动生成 sitemap 提交提醒，触发 AI 爬虫快速抓取

【模块3 · AI 排名每日监测】—— 每天知道自己在哪
  内置 49 个户外路灯核心词+长尾词，可自增
  监测 3 个平台：ChatGPT / Bing AI / Google SGE
  （说明：AI 搜索无公开 API 且需海外环境，采用
   「监测提示词模板 + 录入结果 + 自动趋势分析」的落地方式）
  每日生成排名趋势，自动标注升/降/新进/消失
  自动输出优化建议（未出现→补内容；前3→保持更新）

【模块4 · 线索与效果统计】—— 把排名变成订单
  归集来自 AI 搜索的询盘线索（公司/联系人/邮箱/WhatsApp/国家）
  按关键词、平台、内容类型统计转化率
  算 ROI（成交额 ÷ 获客成本）
  自动生成月度效果报表

【模块5 · 项目管理与绩效核算】—— 逼任务每天落地
  3 个月分 3 阶段递进（见甘特图）
  2 人角色分工 + 每日任务打卡
  绩效 100% 与完成度挂钩：40% 每日 + 30% 周度 + 30% 月度
  连续 3 天未完成 → 第 4 天起每天额外扣 100 元

四、业务数据流（一条内容怎么变成一单）
──────────────────────────────────────────────
  关键词 → 生成内容(模块1) → 发布(模块2) → AI爬虫收录
      → AI 搜索推荐我方(模块3监测到排名上升)
      → 客户顺着推荐来询盘(模块4录线索)
      → 成交 → ROI 上升(模块4)
      → 复盘绩效(模块5) → 下月加码有效关键词

五、为什么这套能排名进前 3
──────────────────────────────────────────────
  1. 结构化数据（JSON-LD）让 AI 能「读懂」我们是供应商
  2. 场景化内容精准命中 B 端采购意图（不是泛泛的"太阳能路灯"）
  3. 多平台铺量 → AI 多次看到同一品牌 → 形成「共识推荐」
  4. 持续更新 → AI 认定我们是「活跃」供应商而非僵尸官网
  5. 每天监测 → 发现问题当天补，不靠运气
